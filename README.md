# 夏末蟬鳴的彼岸（Beyond the Summer Cicadas）v2.0

日系心理向視覺小說 / Galgame（純前端 HTML5 + Web Audio + 本地 AI 統一畫風素材），支援電腦與手機瀏覽器直接遊玩。

## 故事簡介
八月下旬，失去雙親的雙生兄妹悠真與琴理回到外公留下的鄉間老宅。面對村落耳語、轉學期限與十年前河堤水閘的塵封往事，「世俗眼光與彼此依存」的拉扯逐漸顯露——你會選擇關緊門窗把時間停在八月，還是與她一同推開那扇通往九月的木門？

## 作品特色
- **深度分支劇本**：71 個劇情節點與 4 種截然不同的結局（True / Normal / Closed / Bitter End）
- **統一賽璐璐美術**：4 張場景背景、8 張雙角色表情立繪、6 張事件／結局 CG（含事件 CG 回想鑑賞室）
- **原創多樂段配樂**：5 首 60～78 秒物理建模鋼琴／大提琴／木吉他無縫循環 BGM 與即時合成環境音
- **完整系統功能**：3 格存讀檔、快速存檔（`Q`）、自動播放（`A`）、已讀快進（`S` / `Ctrl`）、對話紀錄（`L`）、隱藏介面（`H`）、新手導引與跨裝置排版

## 本機執行方式
雙擊執行資料夾內的 `run.bat` 即可自動啟動本機伺服器並支援同網段／VPN 手機連線遊玩。
