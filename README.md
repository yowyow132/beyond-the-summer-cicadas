# 夏末蟬鳴的彼岸（Beyond the Summer Cicadas）v3.0

日系心理懸疑視覺小說 / Galgame（純前端 HTML5 + Web Audio + 本地 AI 統一畫風素材），支援電腦與手機瀏覽器直接遊玩。

## 故事簡介
暴雨停電的第四天深夜，悠真從佛壇底層摸出被撕掉一半的《轉校與撫養權協議書》，手中的舊手電筒卻只剩一顆電池。屋內是默默擋住走道的妹妹琴理，門外是十年前舊宅火災補償者後代、卻急著催促兄妹離開的鄰居夏實——在倒敘交錯的夏末記憶裡，沒有誰的溫柔毫無私心。

## 作品特色
- **StoryScope 非線性分支劇本**：60 個精實劇情節點（停電夜倒敘切入 × 記憶閃回 × 三方攤牌 × 4 種留白結局）
- **統一賽璐璐美術與瞳色鎖定**：5 張場景背景（含停電夜佛壇專用場景）、8 張雙角色表情立繪、6 張事件／結局 CG（含事件 CG 回想鑑賞室）
- **多聲部立體聲配樂與防疲勞音效**：`assets/audio/` 5 首 60～78 秒無縫循環 BGM ＋ Web Audio 即時合成備援與隨機音高微擾（±6%～8%）SFX
- **完整系統功能**：3 格存讀檔、快速存檔（`Q`）、自動播放（`A`）、已讀快進（`S` / `Ctrl`）、對話紀錄（`L`）、隱藏介面（`H`）、新手導引與跨裝置排版

## 本機執行方式
雙擊執行資料夾內的 `run.bat` 即可自動啟動本機伺服器並支援同網段／VPN 手機連線遊玩。
